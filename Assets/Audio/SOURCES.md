# Shop audio sources

Game audio design, fictional phrases, sound synthesis and original music sequencing: Navin Ratnayake (@navinrtnk), 2026.

The door chime, checkout/receipt sounds, cardboard handling, footsteps and boutique theme are generated by `scripts/generate_audio.py` from original oscillator/noise synthesis and note patterns. They do not use sampled game sounds, commercial songs or downloaded sound recordings.

The 20 vocal bites use newly written fictional syllables, synthesized locally with the generic Kokoro `af_heart` and `am_michael` voices. They are not recordings of a person, EA/The Sims dialogue, or Simlish phrases. The source model is [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), released under Apache-2.0, with the developer's [ONNX distribution](https://github.com/thewh1teagle/kokoro-onnx). The model's training-data acknowledgments remain available on its model card. Model terms are preserved in `LICENSES/Kokoro-Apache-2.0.txt`. No exclusive ownership of the model, voice embeddings or training material is claimed.

`sources.json` records the model URLs and SHA-256 hashes, generation phrases/voice IDs, and each shipped WAV's SHA-256, sample rate, channels and duration. `voices.json` contains amplitude envelopes for mouth animation. Only the resulting PCM audio and envelopes ship with the game; model weights, voice embeddings, ONNX Runtime, kokoro-onnx, eSpeak NG, NumPy and SciPy remain ignored development inputs under `.tools`. The game makes no network calls to generate or play audio.

To regenerate, create an isolated Python venv, install `kokoro-onnx==0.4.7`, `numpy`, `scipy` and `soundfile`, then run `python scripts/generate_audio.py`. The script verifies the pinned model input hashes. Neural inference can vary slightly across runtime/platform versions; generated runtime outputs and their manifest are the reviewable game assets. All WAVs use 24 kHz PCM16; the stereo theme loops and the other clips are mono spatial cues.
